Arsitektur yang Dipelajari
SOAP, REST lanjutan, GraphQL, gRPC & microservices

Capaian Pembelajaran Mata Kuliah

  • Mahasiswa mampu menjelaskan evolusi arsitektur layanan dari monolith, SOA, hingga microservices.
  • Mahasiswa mampu merancang dan mengimplementasikan web service menggunakan SOAP, REST lanjutan, GraphQL, dan gRPC.
  • Mahasiswa mampu menerapkan mekanisme keamanan (OAuth2, API key management, mTLS) pada layanan yang dibangun.
  • Mahasiswa mampu merancang arsitektur microservices dengan API gateway, service discovery, dan komunikasi asinkron.
  • Mahasiswa mampu mendokumentasikan, menguji, memonitor, dan men-deploy web service ke platform cloud.
