LAB 01

Setup Environment Lanjutan

Menyiapkan Docker, tools API testing, dan editor sebagai fondasi seluruh praktikum Web Service — dari lab SOAP hingga deployment microservices di akhir semester.

Durasi 100 menit
Format Praktikum Mandiri/Berpasangan
Prasyarat Instalasi bahasa/framework dari mata kuliah Backend Programming
Tujuan Pembelajaran
  • 01Mahasiswa mampu menginstal dan memverifikasi Docker Desktop di komputer masing-masing.
  • 02Mahasiswa mampu menggunakan Postman/Insomnia untuk mengirim request dan memeriksa response API.
  • 03Mahasiswa mampu membuat akun gratis di Neon, Render, dan Cloudflare sebagai persiapan lab-lab berikutnya.
  • 04Mahasiswa mampu menjalankan container Docker pertamanya dan mengonfirmasi environment siap dipakai.
Alat yang Dibutuhkan

Tools Praktikum

Docker Desktop wajib
Untuk menjalankan dan mengemas service dalam container, dipakai mulai lab ini hingga deployment di akhir semester.
Postman / Insomnia wajib
Alat utama untuk mengirim request dan memeriksa response API sepanjang praktikum.
Akun Neon disiapkan
Database PostgreSQL gratis, dipakai mulai lab GraphQL (lab 04-05).
Akun Render disiapkan
Hosting web service, dipakai mulai lab gRPC dan seterusnya.
Akun Cloudflare disiapkan
Untuk sesi edge computing & message queue (lab 08 dan 10).
Editor Kode bebas
VS Code direkomendasikan, tapi editor lain yang sudah biasa dipakai tetap boleh.
Langkah Praktik

Instalasi & Verifikasi

01

Instal Docker Desktop

Unduh dan instal Docker Desktop sesuai sistem operasi masing-masing, lalu verifikasi instalasi lewat terminal:

# cek versi Docker docker --version # jalankan container uji coba docker run hello-world
02

Instal Postman atau Insomnia

Buat akun (opsional) lalu coba kirim request pertama ke API publik untuk memastikan tool berjalan normal, misalnya GET https://jsonplaceholder.typicode.com/posts/1.

03

Daftar Akun Cloud Gratis

Buat akun di tiga platform berikut menggunakan email kampus atau email pribadi — tidak memerlukan kartu kredit:

  • Neon — neon.tech
  • Render — render.com
  • Cloudflare — dash.cloudflare.com
04

Uji Coba Container Sederhana

Jalankan container Nginx sebagai simulasi web service paling sederhana, lalu akses lewat browser di localhost:8080.

docker run -d -p 8080:80 nginx
Checklist Kesiapan
  • Docker Desktop terinstal dan docker run hello-world berhasil
  • Postman/Insomnia terinstal dan berhasil mengirim 1 request percobaan
  • Akun Neon, Render, dan Cloudflare sudah dibuat
  • Container Nginx berhasil diakses lewat browser
